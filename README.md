# VELORA — Clothing & Accessories Concept Store

A complete, responsive multi-page storefront concept built with HTML, CSS and vanilla JavaScript. The visual direction is minimal luxury with warm neutrals: cream, beige, taupe and deep brown. Elegant serif typography is used throughout.

## Pages
- `index.html` — Home, campaign collage, collections, featured products, customer quote and newsletter demo.
- `shop.html` — Product catalogue, category filters, search, sorting, quick view and wishlist.
- `product.html` — Dynamic product details, size selection, add-to-bag and related products.
- `about.html` — Brand story and contact form.
- `cart.html` — Shopping bag, quantity controls and demo checkout.

## Included interactions
- Responsive mobile navigation
- Dark / light theme toggle (preference saved in browser storage)
- Product category filtering, search and sorting
- Quick-view modal
- Product detail pages for the included catalogue
- Wishlist and cart saved in browser storage
- Quantity changes and item removal
- Demo checkout, newsletter and contact form feedback
- Subtle scroll reveal animations

## Run locally
Open `index.html` in a modern browser. No build tools or package installation are required. Product and campaign photography is embedded as image URLs from Unsplash, and the serif typeface is loaded from Google Fonts, so an internet connection is needed for those remote assets. No images or content need to be supplied by the user.

## Demo notice
VELORA is a fictional portfolio concept store. Checkout, newsletter and contact forms are front-end demonstrations only; no payment, order, email or message is sent or stored by a backend.
